# Agent Terminal Homebrew Tap

This public Homebrew tap installs Agent Terminal on macOS 13 and later.

```sh
brew tap 4nuva/agent-terminal
brew trust --cask 4nuva/agent-terminal/agent-terminal
brew install --cask agent-terminal
```

Upgrade with `brew upgrade --cask agent-terminal`.

The Cask and versioned app archives are published here. The DMG is hosted at
`downloads.4nuva.dev`. The first `Casks/agent-terminal.rb` is generated by
`scripts/upload-macos.sh` after the first macOS release archive is uploaded.

Release and credential setup instructions live in `docs/HOMEBREW.md` in the
Agent Terminal source repository.
